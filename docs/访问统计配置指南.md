# 网站访问统计配置指南 — Cloudflare Web Analytics

> 需求:记录网站访问次数,不采集个人隐私信息,通过后台查看数据。
> 方案:Cloudflare Web Analytics(免费、隐私友好、无需 cookie 与同意横幅)。

## 为什么选 Cloudflare Web Analytics

| 特点 | 说明 |
|------|------|
| 免费 | 无需付费,包含在 Cloudflare 账户内 |
| 隐私友好 | **不收集个人身份信息**(无 cookie、无设备指纹、无需同意横幅) |
| 零代码 | 网站托管在 Cloudflare Pages,后台一键开启,自动注入统计脚本,代码无需任何改动 |
| 后台查看 | 数据在 Cloudflare 控制台查看,无需额外登录其他平台 |

## 第一步:一键启用(约 2 分钟)

1. 登录 Cloudflare 控制台:https://dash.cloudflare.com
2. 左侧菜单 → **Workers 和 Pages** → 点击项目 **`inertia-cn`**
3. 进入项目后,顶部 Tab 找到 **设置(Settings)**(或「Analytics」)
4. 找到 **Web Analytics** 区域 → 点击 **启用(Enable)** 或 **创建(Add)**:
   - 如果提示选择站点,选择 `inertiapd.cn`
   - Cloudflare 会自动创建/关联一个 Web Analytics 项目,并在你的 Pages 页面中自动注入统计脚本
5. 保存后即生效

> 如果页面提示需要新建 Web Analytics 项目,也可以到 **Analytics → Web Analytics → Add a site** 手动创建,选择 `inertiapd.cn` 后,再回到 Pages 项目设置里关联。

## 第二步:查看访问次数

1. Cloudflare 控制台 → **Analytics** → **Web Analytics**
2. 选择 `inertiapd.cn` 项目,即可看到:
   - **Visits** — 访问次数(主要指标)
   - **Unique visitors** — 独立访客(不包含个人身份)
   - **Page views** — 页面浏览量
   - 按页面、来源、地区、设备等维度的明细

- 统计脚本需要**网站已部署**才会生效。若线上还是旧版本,请先推送最新代码:
  ```powershell

  ```
- Web Analytics 统计的是页面被加载的次数,不包含爬虫/机器人过滤后的隐私数据,完全符合"不采集隐私信息"的要求。
- 如果日后想要更细的转化追踪,可再考虑接入表单提交事件(需改代码)。

## 常见问题

| 问题 | 解决办法 |
|------|---------|
| 找不到 Web Analytics 入口 | 检查是否登录了正确的 Cloudflare 账户(网站所在账户) |
| 数据为空 | 确认网站已通过 `inertiapd.cn` 访问且已部署;刚启用时需等待几分钟数据积累 |
| 想在前台显示访客数字 | 当前方案是后台查看;如需页面上显示计数器,需另做方案(联系开发) |
